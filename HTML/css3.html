CSS Height, width & max-width

Properties of Height & width:-

  1. auto :- This is default. It calculate the height and width of the browser.
  2. length :- px,cm, em, rem, vh,vw
  3. % :- 100%, 70%
  4. Initial :- Default value set
  5. Inherit :-Tt compare with parent value.
